# Munshi AI — Project Documentation v3

## 1. Product
Munshi AI is a simple, trustworthy digital business assistant for Pakistani general-store / kiryana shopkeepers.

The product replaces scattered notebooks and manual tracking for:
- sales
- khata
- customers
- products
- inventory
- orders
- offers
- basic reports

The product should feel like a **digital munshi sitting beside the shopkeeper**, not an enterprise ERP and not a generic AI startup.

## 2. Current MVP Stack
- React
- Supabase Auth
- Supabase PostgreSQL
- Supabase Row Level Security (RLS)

## 3. Explicitly Not in MVP
- Node.js backend
- Express.js
- MongoDB
- n8n
- automation engine
- agentic workflows
- AI assistant
- WhatsApp/SMS automation

These belong to future phases only when the product has a clear reason for them.

## 4. UI Direction — Approved Reference
The approved visual direction is a **clean, minimal, modern SaaS dashboard** inspired by the supplied visual reference.

Core qualities:
- spacious
- simple
- premium
- calm
- highly readable
- practical
- polished without looking over-designed

The interface should use:
- a light neutral application background
- a compact persistent desktop sidebar
- a clean top utility/header area
- white or near-white content surfaces
- restrained rounded corners
- very subtle borders/shadows
- a small number of purposeful accent colors
- strong typography hierarchy
- clean tables and charts
- generous but controlled whitespace

Avoid:
- AI sparkles
- neural/robot motifs
- decorative dots
- random symbols
- excessive gradients
- glassmorphism
- excessive shadows
- card-inside-card layouts
- giant KPI walls
- futuristic dashboard aesthetics
- unnecessary illustrations
- ornamental UI

## 5. Responsive Strategy
Desktop/laptop is the primary design target.

Tablet and mobile are responsive adaptations of the same information architecture. They are not separate product identities.
