# Munshi AI — Stitch Prompt Pack v3

## Global Instruction
Use the supplied Munshi AI visual reference as the design-language reference.

Do NOT copy its content or branding.

The target is:
- clean minimal
- modern SaaS
- spacious
- premium
- practical
- purposeful color
- restrained rounded surfaces
- desktop-first

Avoid:
- AI sparkles
- robot/neural motifs
- decorative dots
- random symbols
- excessive gradients
- glassmorphism
- excessive shadows
- giant KPI walls
- card-inside-card layouts
- unnecessary illustrations
- futuristic UI
- excessive animations

Do not design all screens in one generation.

---

# Prompt 01 — App Shell + Dashboard

Design the desktop-first responsive web application shell for **Munshi AI**, a digital business assistant for Pakistani general-store and kiryana shopkeepers.

Use a clean minimal modern SaaS aesthetic inspired by the supplied visual reference.

The interface should feel calm, trustworthy, practical and premium.

Desktop is the primary target.

Create:
- persistent compact left sidebar
- Munshi AI brand area
- Dashboard
- Sales
- Products
- Inventory
- Customers
- Khata
- Orders
- Offers
- Reports
- Settings separated near the bottom
- clean top utility bar
- global search
- notification control
- shopkeeper profile

Dashboard:
- greeting
- date selector
- 4 compact summary metrics
- Sales Overview chart
- Top Selling Products ranked list
- Recent Sales table
- Inventory Status section

Use a light neutral background, white surfaces, subtle borders, restrained rounded corners and very soft shadows.

Use a small coordinated accent palette. Do not use gradients or decorative dots.

The dashboard must not look like an enterprise ERP and must not look AI-generated.

# Prompt 03 — Add/Edit Product

Create a clean desktop-first Add Product form.

Fields:
- Product Name
- SKU
- Selling Price
- Cost Price
- Stock Quantity
- Low Stock Threshold

Group fields logically.

Use one strong primary Save button and a quiet Cancel action.

Do not use a multi-step wizard.

# Prompt 12 — Interaction Quality Pass

Review the Munshi AI UI for polish.

Fix:
- inconsistent spacing
- weak hierarchy
- unnecessary borders
- excessive shadows
- awkward alignment
- layout shifts
- inconsistent icon sizes
- inconsistent corner radii
- overly strong colors
- decorative elements

Pay special attention to dynamic numbers and timers.

Reserve stable widths so changing values never move neighboring elements.

The final result should feel intentionally designed, quiet and premium.
