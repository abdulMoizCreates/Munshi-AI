# Munshi AI — Product Roadmap

## Phase 0 — Definition
- PRD
- Personas
- User flows
- UX specification
- Design system
- Architecture
- Database schema
- Security model

## Phase 1 — Foundation
- React project setup
- Supabase project
- Authentication
- Profile/role system
- Shop creation
- RLS
- Application shell/navigation

## Phase 2 — Core Business
- Products
- Customers
- Dashboard
- Sales
- Inventory
- Khata

## Phase 3 — Supporting Features
- Orders
- Offers
- Reports
- Subscription foundation
- English/Roman Urdu polish

## Phase 4 — Testing & Production
- Cross-user authorization testing
- RLS testing
- Mobile responsiveness
- Error states
- Performance
- Security review
- Deployment
- Trial onboarding

## Phase 5 — Validation
Measure:
- Signup completion
- Shop setup completion
- First product added
- First sale recorded
- Repeat usage
- Trial retention
- Most-used features
- User feedback

## Phase 6 — Intelligence
Only after core product usage is validated:
- AI business queries
- AI insights
- Smart recommendations

## Phase 7 — Automation
Introduce n8n where automation provides measurable value:
- Low-stock notifications
- Khata reminders
- Scheduled reports
- Customer communications

## Phase 8 — Agentic Workflows
Potential capabilities:
- Natural-language sales entry
- Business-data queries
- Inventory recommendations
- Multi-step controlled actions

Agents must use explicit tools and permission boundaries.

## Phase 9 — Backend Evolution
If scale, security, integrations, performance, or business requirements justify it:
- Node/Express custom backend
- Additional service layer
- Database architecture evolution
- MongoDB only if technically justified

## Guiding Rule
Do not build future complexity before current users need it.
