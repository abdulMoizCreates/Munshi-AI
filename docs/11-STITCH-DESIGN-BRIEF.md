# Munshi AI — Stitch Design Brief v3

## 1. Design Objective

Create a web application that feels like a **real, polished business product**, not an AI-generated concept.

The supplied visual reference is the primary inspiration for:
- simplicity
- layout balance
- color interaction
- typography hierarchy
- spacing
- surface treatment

Do not copy its branding or health-specific content.

## 2. Visual Direction

Keywords:

**Clean Minimal**
**Soft Modern SaaS**
**Premium Practical**
**Purposeful Color**
**Strong Hierarchy**
**Quiet Interaction**

## 3. Application Shell

Desktop:
- light background
- persistent left sidebar
- clean top header
- large but controlled main content area

Sidebar should feel calm and compact.

Header:
- global search
- notifications
- shopkeeper profile

## 4. Dashboard

Use a composed layout rather than a card grid explosion.

Suggested:

```text
Greeting + date
────────────────────────────────────

4 compact summary metrics

────────────────────────────────────

Sales Overview        Top Selling Products
Large chart            Ranked list

────────────────────────────────────

Recent Sales           Inventory Status
Table                   Progress/status rows
```

The dashboard should have visual rhythm similar to a premium SaaS product.

## 5. Color Interaction

Use a neutral base and a limited accent family.

A possible direction:
- dark navy/ink for primary text
- warm/soft off-white background
- green for healthy/positive business states
- one secondary pastel accent
- warning amber
- danger red

The exact brand palette remains provisional.

Colors must feel coordinated rather than random.

## 6. Typography
Use a modern sans-serif.

Large numbers should be visually strong.

Headings should be confident but not oversized.

Metadata should be quiet.

## 7. Components
Prefer:
- rounded surfaces
- subtle borders
- very soft shadows
- simple icon containers
- clean tables
- progress bars
- compact dropdowns
- restrained badges

Avoid:
- floating blobs
- gradients
- glow effects
- AI sparkles
- random decorative dots
- excessive pill controls

## 8. Spacing
The interface should breathe.

Use generous internal padding while keeping business information dense enough to be useful.

## 9. Motion
Only subtle transitions.

No animation should move surrounding layout unexpectedly.

## 10. Important Rule
The UI should look designed by a strong product designer who intentionally removed unnecessary elements.

**Less, but better.**
